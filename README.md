# CampGo-Cho thuê đồ cắm trại

## Giới thiệu

 Website cho **thuê** đồ *cắm trại*

## Cấu trúc thư mục

| Thư mục | Nội dung |
| :---: | :---: |
| `data/` | Bảng tính đơn thuê |
| `logs/` | Log truy cập website |
| `docs/` | Tài liệu bàn giao |

## Kiểm tra danh mục dự án

```powershell
Get-ChildItem -Recurse -Force
```
